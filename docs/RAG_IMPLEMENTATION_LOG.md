- Metric definitions: for the set `Q+` of queries with at least one expected product and `n=|Q+|`, let `E_q` be the expected product-ID set and `T5_q` be the first five unique ranked product IDs. `R5(all) = (1/n) * Σ(q∈Q+) |T5_q ∩ E_q| / |E_q|`. `R5(capped) = (1/n) * Σ(q∈Q+) |T5_q ∩ E_q| / min(5, |E_q|)`. `ceiling(all) = (1/n) * Σ(q∈Q+) min(5, |E_q|) / |E_q|`; this is the maximum possible `R5(all)` under a five-result cutoff for those labels. No-result queries are excluded from these three denominators and are measured separately by `no_result_empty`.
- The fixture-count question is settled by the fixture and cache keys: 96 development rows (88 relevant and 8 no-result) plus 5 existing author rows contain 93 unique query texts, because 8 rows reuse a query key.
